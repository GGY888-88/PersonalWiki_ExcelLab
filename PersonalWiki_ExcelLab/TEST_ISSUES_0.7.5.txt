PersonalWiki_ExcelLab 0.7.5 - Test issues / pending verification

Fixed in TestPack fix1:
- The original run-acceptance-tests.ps1 contained Traditional Chinese text saved as UTF-8 without a BOM. Windows PowerShell 5.1 may decode that file using the active ANSI code page, causing garbled text and a parser error near the final Write-Host statement.
- The fixed script uses ASCII-only source text, so it does not depend on PowerShell's source-file encoding detection.

Pending user-side tests:
1. Run the acceptance script on Windows with .NET 10 SDK installed.
2. Confirm dotnet restore/build succeeds.
3. Review AcceptanceTestReport.json for PASS/FAIL results.
4. Verify negative-test exit-code handling.
5. Excel import against a COPY of the original workbook remains a separate manual test; the acceptance script does not modify or import the user's original Excel file.

Known environment limitation:
- This package was assembled in an environment without the .NET SDK and without Windows PowerShell, so the PowerShell script could not be executed here. ZIP integrity is checked separately.
