# PersonalWiki ExcelLab 4.6.2 - Main UI Refine

## 本次修改

1. 主畫面功能按鈕尺寸設定可進一步縮小：寬度下限由 100 調整為 40（96 DPI 基準），高度下限由 36 調整為 20；寬度每次 5、高度每次 2。這只影響主畫面功能按鈕，不影響新增／編輯條目對話框按鈕。
2. 主畫面功能按鈕內距縮小，按鈕字體調整為 9pt，降低 300% DPI 下的視覺佔用；仍保留按鈕文字自動量測及換行排列。
3. 新增 `VerticallyCenteredTextBox`，套用於資料庫路徑、全文搜尋及標籤搜尋欄位，透過原生 EDIT 控制項格式矩形將文字垂直置中。
4. 不修改日期篩選、查詢服務、資料庫 Schema、Models、CLI、Excel 欄位對應及匯入交易流程。
5. 新增三個雙擊執行批次檔，降低手動 PowerShell 操作：
   - `01_建置程式.bat`
   - `02_啟動程式.bat`
   - `03_建置並啟動.bat`（單次雙擊即可建置後啟動，不需中途再按鍵）
6. 依 Windows CMD 實際錯誤回報，修正批次檔編碼與命令解析：三個 BAT 改為純 ASCII + CRLF，不再使用 UTF-8 中文輸出或 `chcp 65001`；改以 `pushd "%~dp0"` 定位專案並使用相對路徑，避免中文使用者路徑與 CMD OEM 編碼混用造成命令被拆解。`03_建置並啟動.bat` 不再呼叫另一個中文檔名 BAT，改為獨立執行建置及啟動流程。

## 操作方式

1. 解壓縮 ZIP。
2. 第一次建置請雙擊 `01_建置程式.bat`；或直接雙擊 `03_建置並啟動.bat`（單次雙擊即可建置後啟動，不需中途再按鍵）。
3. 後續程式碼未變更時，可雙擊 `02_啟動程式.bat`。
4. 建置輸出保存在 `build_release.log`；失敗時批次檔會保留視窗並顯示錯誤。BAT 使用純 ASCII 命令文字，以相容繁體中文 Windows CMD。
5. 主畫面上方點選「主畫面功能按鈕大小」，可將寬度調低至 40、高度調低至 20（96 DPI 基準）。300% DPI 下的實際尺寸會依縮放比例換算。

## 驗收狀態

- 已完成來源碼差異檢查及 ZIP 完整性檢查。
- 本輪 BAT 修正已完成靜態檢查：三個檔案均為 ASCII、CRLF，無 UTF-8 中文字串、無 `chcp`、無巢狀呼叫中文檔名；建置／啟動錯誤分支均保留視窗。
- 本建置環境沒有 .NET SDK，未能執行實際 `dotnet build`。
- `VerticallyCenteredTextBox` 的 300% DPI 垂直置中效果，及縮小按鈕後的可讀性，需在 Windows 300% 環境實機確認。
- 建議使用測試資料庫驗收，不需執行 Excel 匯入。

## 保護範圍

本次只調整桌面 UI 控制項與設定值範圍，並新增建置／啟動批次檔及文件。資料庫結構、資料存取服務、查詢邏輯、Excel 匯入流程均不在本次修改範圍。
