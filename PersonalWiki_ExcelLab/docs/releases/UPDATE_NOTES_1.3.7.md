# PersonalWiki ExcelLab 1.3.7 更新說明

## Excel 工作表個別欄位版面
- 匯入 Excel 時，每張工作表仍依各自的欄位對應設定匯入。
- 條目「自訂欄位」頁籤改為橫向表格：第一欄為欄位值，其後每個欄位各自成為一欄，欄名取自該筆條目的匯入欄位標題。
- 欄位順序沿用該工作表匯入映射中的欄位順序；不同工作表因欄位名稱及順序不同，顯示不同的表格版面。
- 版面由條目已保存的欄位資料呈現，不需額外修改 SQLite Schema，也不會影響既有條目或匯入紀錄。
- 無自訂欄位的手動建立條目仍顯示原本的欄位／內容／類型欄頭。

## 安全與相容性
- 不修改原始 Excel。
- 不修改 SQLite Schema（仍為 v1）。
- 不新增 NuGet 相依套件。
- 本版本僅調整桌面端欄位呈現，不會改寫既有資料。

## 測試狀態
- 已檢查程式碼修改位置及 ZIP 封裝內容。
- 尚未在 Windows/.NET 10 環境編譯或執行；需由 Windows 實機確認欄位多時的水平捲動及不同工作表版面。
