# PersonalWiki ExcelLab 1.2.3（桌面介面與匯入易用性修正版）

## 修正內容
- 條目新增／編輯視窗使用可調整大小的表格版面，放大輸入區，改善 Windows 字型／DPI 下文字裁切。
- 筆記與圖片工具列移到頁籤頂部；筆記和圖片說明使用可調整大小的多行輸入視窗。
- 圖片加入採 `ON CONFLICT(entry_id,file_path) DO UPDATE`，同一條目重複選取同一圖片不再出現 SQLite UNIQUE constraint failed；新說明非空白時更新，留空保留既有說明。
- 圖片無法預覽或原始檔遺失時仍顯示關聯卡片，不再靜默略過；可選取該關聯以移除資料庫關聯（不刪除原圖）。
- 搜尋新增 `LIKE` 部分文字備援，支援條目名稱及摘要片段搜尋，同時保留 FTS5 查詢。
- 封存篩選加上還原用途說明，還原按鈕依選取項目狀態動態顯示；操作後顯示全部條目。
- 資料庫路徑標示為「目前資料庫位置」；Excel 主按鈕改為「Excel 匯入精靈」。
- Excel 預覽與欄位設定視窗改為可調整大小，底部按鈕固定於可見列；欄位用途使用中文文字，屬性欄位代碼自動產生。
- 整張不需匯入的工作表可將所有欄位設為「忽略」；映射驗證、Dry-run、安全匯入均會略過該工作表。
- 增加清理規則勾選畫面及 Dry-run 問題列摘要；檢查預設全開，問題列仍會阻止匯入，停用檢查前顯示警告。

## 安全限制維持
- SQLite Schema Version 1 不變。
- 原始 Excel 以唯讀方式開啟，不會修改或覆寫。
- 匯入仍需預檢、目標資料庫健康檢查、建立並驗證新備份、交易式匯入及匯入批次驗證。
- 不會自動清理、刪除或略過問題資料；只有使用者明確停用相應檢查後，才會接受該類原始資料。
- 圖片只建立資料庫關聯，不複製、移動或刪除硬碟原圖。
- 不新增 NuGet 套件。既有套件：DocumentFormat.OpenXml 3.5.1、Microsoft.Data.Sqlite 10.0.14。

## 更新方式
1. 解壓縮至新資料夾，保留原本 1.2.2 及資料庫不動。
2. 由新資料夾啟動：
   ```powershell
   dotnet run --project .\PersonalWiki.Desktop\PersonalWiki.Desktop.csproj -c Release
   ```
3. 使用「開啟上次資料庫」或「開啟資料庫」載入原有 `.db`。不要把 `samples` 當成資料庫目錄；畫面上的「目前資料庫位置」才是正在使用的資料庫完整路徑。
4. Excel 測試檔位於 `samples\PersonalWiki_Import_Sample.xlsx`。正式匯入前務必確認目前資料庫路徑及備份目的檔路徑。

## 驗證狀態與限制
- 已用 SQLite 測試部分文字搜尋（完整名稱、名稱片段、摘要片段）可命中。
- 已用 SQLite 測試同一條目重複加入相同路徑時只保留一筆關聯，並可更新說明。
- 已完成程式碼差異檢查及 ZIP `unzip -t` 完整性檢查。
- 此工作環境沒有 `dotnet`、`csc` 或 Windows Forms 執行環境；未執行 C# Build、Windows DPI 實際顯示、桌面啟動或端到端 Excel 匯入。需由使用者 Windows/.NET 10 環境驗收。
