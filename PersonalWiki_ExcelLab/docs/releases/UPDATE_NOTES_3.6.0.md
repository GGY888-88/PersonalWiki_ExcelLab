# 3.6.0 重建整合更新說明

> 本版由 3.0.0 可取得原始碼依既有開發紀錄重建；屬恢復版，不宣稱取回上一對話未打包的工作目錄。

- 搜尋新增五種穩定排序：更新時間新到舊、名稱正序／反序、建立時間新到舊／舊到新。
- 搜尋分頁固定上限 200 筆；排序欄位採白名單，查詢仍為唯讀與參數化 SQL。
- 每頁標籤透過單次批次查詢載入，避免逐筆查詢。
- 備份／還原目的地檢查 SQLite 主檔、WAL、SHM、Journal 完整檔案組；提交前再次檢查並使用不覆蓋移動。
- 還原後驗證失敗時，只清理由本次呼叫建立的目標及 SQLite sidecar，且清理錯誤不遮蔽原始例外。
- 新增唯讀相關條目建議，依共用標籤與相同類型排序，不建立持久關係、不修改資料庫。
- 桌面新增條目標籤頁、來源追溯頁、相關條目頁；標籤新增／移除只作用於目前條目，來源追溯及相關條目唯讀。
- 新增 48 項 LRU 圖片縮圖快取，使用檔案大小／修改時間判斷快取有效性，讀取採共享讀取並回傳獨立 Bitmap 副本。
- 新增 Schema v1 合成測試資料庫及圖片、Excel mapping/rules 樣本。
- SQLite Schema、NuGet 套件、資料庫位置與桌面設定位置不變。
