# PersonalWiki ExcelLab 2.0.0 測試指南

## 環境
Windows 10/11、.NET 10 SDK。先解壓 ZIP，使用全新測試輸出資料夾。

## CLI 自動化驗收
```powershell
.\scripts\run-acceptance-tests.ps1 -OutputRoot .\AcceptanceTestOutput_200
```
腳本會自行 restore/build，建立獨立測試資料庫，執行備份／還原安全負向測試、完整性與索引檢查、各項唯讀稽核報告，以及 2.0.0 搜尋回歸（自訂欄位值、筆記正文、分頁結果）。輸出目錄必須不存在。

## 多工作表獨立版面測試
使用隨附 `samples\PersonalWiki_MultiLayout_Test.xlsx`，在 Excel 匯入精靈中逐張工作表檢查：
1. 「人物」欄位順序：名稱、簡介、生日、代表作品。
2. 「設備」欄位順序：設備名稱、型號、購入日期、保固到期、備註。
3. 「閱讀清單」欄位順序：書名、作者、閱讀狀態。
4. 切換工作表時，欄位標題及順序必須跟隨該工作表，不得套用其他工作表版面。
5. 缺值欄位應留白，不得造成後續欄位位移。
6. 來源活頁簿不得被修改；正式匯入前仍須預檢、健康檢查、建立並驗證新備份、交易式匯入及批次驗證。

## 桌面人工驗收
沿用 `DESKTOP_UI_TEST_MATRIX_1.5.0.md`：包含高 DPI、多螢幕、縮放、視窗尺寸、封存／還原、圖片關聯、資料庫健康檢查與立即備份。桌面測試必須使用測試資料庫，不可使用唯一正式資料庫。
