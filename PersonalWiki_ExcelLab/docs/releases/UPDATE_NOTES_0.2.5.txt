PersonalWiki ExcelLab 0.2.5 更新紀錄

新增命令：
import-clean-check <file.xlsx|file.xlsm> <mapping.json> [report.json]

功能：
- 依欄位對應設定，只檢查已指定匯入用途的欄位。
- 檢查 Title 欄位空白、重複及前後空白。
- 檢查已對應欄位的前後空白、控制字元及常見 Excel 錯誤值。
- 顯示問題筆數；可輸出 JSON，保留最多 20 個問題列號樣本。
- 只讀取來源 Excel，不會自動修正、刪除或寫入資料庫。

用法：
dotnet run -c Release -- mapping-template .\資料.xlsm .\mapping.json
# 編輯 mapping.json，至少指定一個 Title 欄位後：
dotnet run -c Release -- mapping-check .\資料.xlsm .\mapping.json
dotnet run -c Release -- import-clean-check .\資料.xlsm .\mapping.json
dotnet run -c Release -- import-clean-check .\資料.xlsm .\mapping.json .\Reports\clean-check.json

相依套件：未新增。
既有功能：保留 0.2.4 原有命令與服務。
解壓資料夾：PersonalWiki_ExcelLab，不帶版本號。
尚未在 Windows .NET 10 環境實際編譯，需由使用者端建置確認。

判斷規則：
- 重複標題以去除前後空白後、不區分大小寫比較。
- 空白資料列不計入掃描筆數。
- 公式不會重新計算；錯誤值只依檔案內可讀取的文字判斷。
- 此版本只產生檢查報告，不會清理資料。
