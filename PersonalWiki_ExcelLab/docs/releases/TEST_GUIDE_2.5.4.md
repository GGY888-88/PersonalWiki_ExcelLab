# 2.5.4 測試指南

## 本版重點：主畫面功能按鈕尺寸

1. 以舊版已存在的 `%LOCALAPPDATA%\PersonalWiki\desktop-settings.json` 啟動，確認舊設定檔可讀取，不要求刪除或重建。
2. 主畫面點選「主畫面功能按鈕大小...」，確認有寬度與高度欄位，預設值為 220 × 64（96 DPI 基準）。
3. 設定寬 260、高 80 並儲存；確認主畫面「新增條目」「編輯條目」「Excel 匯入精靈」及其他工具列按鈕立即變大，文字完整。
4. 確認工具列按鈕不換行，按鈕超出視窗寬度時可水平捲動。
5. 將主畫面設定改為寬 180、高 48；確認所有工具列按鈕同步縮小，文字仍在可讀範圍（若使用者設得太小，屬設定結果，可再次調大）。
6. 點選「輸入視窗按鈕大小...」修改尺寸；確認主畫面工具列尺寸不變。
7. 開啟新增條目與編輯條目視窗，確認只有其中的「確定儲存／取消」使用輸入視窗尺寸設定。
8. Windows 顯示縮放 100%、125%、150%、200%、250%、300% 各啟動一次，確認工具列列高隨實際 DPI 更新，按鈕文字上下不被裁切。
9. 在不同 DPI 螢幕間移動主視窗，確認 `DpiChanged` 後按鈕及工具列列高重新計算。
10. 關閉並重開程式，確認兩組尺寸各自保留且互不影響。

## 回歸檢查
- 開啟／建立資料庫、搜尋、分頁、選取條目、新增／編輯條目。
- 原有輸入視窗按鈕設定仍有效。
- 設定 JSON 保持有效；其他既有設定（LastDatabasePath、EntryButtonWidth、EntryButtonHeight）不得被清除。
- SQLite Schema 仍為 `user_version=1`；本版不執行資料庫 migration。

## 測試狀態
目前打包環境沒有 .NET SDK、Windows 或 PowerShell，因此本指南列出的 WinForms DPI／互動測試尚未實際執行；不可將其標示為已通過。
