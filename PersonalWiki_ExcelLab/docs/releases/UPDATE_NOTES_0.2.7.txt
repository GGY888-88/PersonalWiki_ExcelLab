PersonalWiki ExcelLab 0.2.7 更新紀錄

本版目的
強化欄位 mapping 與清理規則設定的深度驗證，避免錯誤或不完整 JSON 在後續處理時造成例外或錯誤對應。

新增／強化
1. mapping-check：檢查工作表設定重複、空白名稱、Columns 空值、欄位設定空值、SourceIndex 非正整數或重複、標題列缺失、FirstDataRow 不在標題列之後。
2. mapping-check：檢查來源欄位名稱/索引、TargetField 前後空白與重複；提醒 Unmapped/Ignore 欄位殘留 TargetField，以及未列入 mapping 的來源欄位。
3. clean-rules-check：檢查 rules.Sheets、工作表規則、RuleId、Action、TargetFields 空值；檢查 TargetFields 空白或前後空白。
4. mapping 未通過驗證時，clean-rules-check 停止後續規則比對並回報原因，避免不安全的深層存取。

安全限制
- 所有檢查均為唯讀，不修改來源 Excel、mapping JSON、rules JSON 或資料庫。
- 清理規則仍只允許 Action=Review，不會自動修改或刪除資料。
- 本版尚未實作資料清理、dry-run 匯入或正式資料庫匯入。

命令
 dotnet run -c Release -- mapping-check <file.xlsx|file.xlsm> <mapping.json>
 dotnet run -c Release -- clean-rules-check <file.xlsx|file.xlsm> <mapping.json> <rules.json>

依賴
無新增套件；沿用 DocumentFormat.OpenXml 3.5.1、Microsoft.Data.Sqlite 10.0.14。

測試狀態
目前執行環境未提供 dotnet SDK，未能實際編譯或執行 CLI 測試。已完成本次修改範圍的靜態檢查與 ZIP 完整性檢查；不可視為已通過編譯或執行驗收。
