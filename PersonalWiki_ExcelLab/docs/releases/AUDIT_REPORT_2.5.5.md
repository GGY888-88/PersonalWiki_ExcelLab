# 2.5.5 靜態稽核報告

## 修改原因
2.5.4 將所有工具列按鈕固定成同一寬度與高度，預設 220×64。這造成按鈕視覺上過大，長標籤又會因固定寬度換行；資料庫路徑列仍用 FlowLayoutPanel 加固定 1120px 寬文字框，螢幕空間不足時可能被擠出可視區。按鈕文字尾端「...」是程式明確寫入的標籤，不是動態截斷標記。

## 修正
- 主畫面功能按鈕預設改為 100×68；寬度改為最小寬度，按鈕依文字自然放寬，避免長標籤折成多行；高度仍由設定控制。
- 舊版預設 220×64 自動遷移到 100×68；非舊預設值保留。
- 主畫面資料庫路徑列改為 TableLayoutPanel 百分比欄位，路徑文字框 Dock Fill，移除固定 1120px 寬度。
- 路徑框加入 Ctrl+A／Ctrl+C 說明、雙擊全選複製及 ToolTip。
- 移除工具列按鈕尾端「...」，避免被誤認為文字裁切。
- 兩組按鈕尺寸設定仍分開。

- [x] 長標籤按鈕採 AutoSize GrowAndShrink，設定寬度只作為 MinimumSize。
- [x] 不再將工具列按鈕 MaximumSize 鎖定為相同固定寬度。
- [x] 資料庫路徑列移除固定 1120px，改為百分比填滿。
- [x] 指定工具列標籤移除尾端省略號。
- [x] 版本及交接文件更新。

- [ ] Windows 100%–300% DPI 實機測試（目前環境非 Windows）。

## 風險與限制
自然寬度會讓長標籤按鈕佔用較多工具列寬度；工具列仍使用單列水平捲動。實際字型量測、DPI 縮放與路徑列高度仍須 Windows 實機驗收。
