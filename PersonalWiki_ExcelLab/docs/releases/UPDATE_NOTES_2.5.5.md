# PersonalWiki ExcelLab 2.5.5 更新說明

## 主畫面功能按鈕
- 新預設尺寸：寬 100、高 68（96 DPI 基準）。
- 寬度設定代表最小寬度，長標籤會依文字自然放寬；不再強制所有按鈕固定寬度，也不會為了塞進固定寬度而折成多行。
- 高度按設定值套用，並依 DPI 換算；工具列列高依按鈕實際高度同步更新。
- 若舊設定檔剛好存有 2.5.4 未修改過的舊預設 220×64，讀取時轉為 100×68；其他自訂尺寸不變。

## 資料庫位置列
- 由固定寬度的 FlowLayoutPanel 改成 TableLayoutPanel，路徑輸入框填滿視窗可用寬度，避免被其他控制項擠出或遮住。
- 路徑框支援 Ctrl+A／Ctrl+C；雙擊會全選並複製完整路徑，ToolTip 說明完整路徑操作。

## 按鈕文字
- 移除主工具列按鈕名稱尾端的「...」。該符號原本是 Windows UI 常見的「按下後會開啟對話框」標示，不是尚有文字被截斷；現在移除以免誤解。

## 保留項目
- 「輸入視窗按鈕大小」只控制新增／編輯條目視窗內的儲存／取消按鈕。
- 「主畫面功能按鈕大小」只控制主畫面工具列按鈕。
- SQLite Schema `user_version=1`、NuGet 套件、資料庫與設定檔位置不變。
