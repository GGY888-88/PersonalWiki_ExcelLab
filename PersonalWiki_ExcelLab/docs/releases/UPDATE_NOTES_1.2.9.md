# 1.2.9 更新內容

- 新增主畫面「輸入視窗按鈕大小...」設定。
- 使用者可自行調整新增／編輯條目視窗的確定、取消按鈕寬度與高度。
- 設定儲存在 `%LOCALAPPDATA%\PersonalWiki\desktop-settings.json`，不影響資料庫。
- 尺寸以 96 DPI 為基準，顯示時依目前 DPI 換算；預設寬 160、高 64。
- 保留 1.2.8 編輯名稱初始顯示開頭的修正。
- SQLite Schema v1 不變；NuGet 相依套件不變。
- ZIP 內附啟動 PersonalWiki.bat。
- 尚未完成 Windows 300% DPI 實機 Build／介面驗收。
