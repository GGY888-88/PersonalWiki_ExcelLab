# 3.8.0 更新說明（整合開發候選）

## 條目關係瀏覽
- 相關條目清單除共用標籤數外，新增顯示實際共用標籤名稱，方便判斷推薦原因。
- 相關條目仍以唯讀查詢計算，依共用標籤與相同類型排序；封存條目不列入推薦。
- 不建立持久關係、不修改 Schema。

## 圖片管理
- 可編輯既有圖片關聯的說明，最多 2,000 字；留空可清除說明。
- 可檢查選取圖片原始檔是否存在，並以 SHA256 比對建立關聯時的雜湊，辨識原圖遺失或內容被替換／修改。
- SHA256 檢查以共享讀取方式開啟檔案，不會修改或刪除原始圖片。
- 移除圖片仍只刪除資料庫關聯，不刪除硬碟原圖。

## 相容性與限制
- SQLite Schema 維持 `user_version=1`，不新增資料表、欄位或索引。
- NuGet 套件、資料庫位置及桌面設定位置不變。
- 標籤分類持久化需要新 Schema；本版不自行新增分類欄位，避免未經批准的資料庫遷移。現有標籤管理功能保留。
