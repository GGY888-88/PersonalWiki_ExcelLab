# 3.7.0 測試指南

在專案根目錄執行：

```powershell
python scripts/run-3.7.0-python-tests.py
```

新增 `test-3.7.0-composite-filters.py`，以合成 SQLite fixture 驗證建立／更新日期邊界、標籤與類型／封存交集、CLI 參數、桌面清除條件及查詢安全契約。並執行 3.6.0 回歸測試。

## 手動測試
1. 開啟合成測試資料庫。
2. 分別勾選建立日期起／迄、更新日期起／迄；確認迄日當天資料包含在結果中。
3. 同時設定關鍵字、類型、標籤、封存狀態與日期，確認條件為 AND 交集。
4. 輸入起日晚於迄日或無效日期，確認顯示錯誤且不修改資料庫。
5. 使用「清除條件」，確認文字、類型、標籤、封存、日期、排序及頁碼全部回到預設。
6. 使用 CLI `entry-query` 分別傳入日期參數及排序參數，確認輸出欄位與分頁正確。

Python 測試不等於 .NET／Windows 執行期驗收。
