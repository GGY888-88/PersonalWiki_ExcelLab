# 4.1.0 更新說明（第一批：桌面搜尋結果管理）

## 新增功能
- 桌面搜尋結果新增「複製選取摘要」按鈕。
- 可沿用結果清單既有 Ctrl／Shift 多選，一次複製多筆摘要。
- 複製內容包含名稱、類型、摘要、更新時間、封存狀態及條目 ID，並以分隔線區隔不同條目。
- 未選取項目時按鈕停用；選取後自動啟用。
- 複製只讀取目前畫面已載入的搜尋結果，不重新查詢、不修改資料庫、不修改圖片或關聯。
- 複製成功後狀態列顯示筆數；剪貼簿錯誤沿用既有錯誤呈現方式。

## 使用方式
1. 開啟知識庫並執行搜尋。
2. 在左側搜尋結果清單選取一筆或多筆條目（Ctrl／Shift 多選）。
3. 按「複製選取摘要」，即可貼到記事本、文件或其他程式。

## 安全與相容性
- 純桌面呈現功能，沒有新增資料庫寫入操作。
- SQLite Schema 維持 `PRAGMA user_version=1`，不新增／修改資料表、欄位、索引或 migration。
- DB 路徑、桌面設定路徑及 NuGet 版本不變。
- CLI `entry-query --output` 及原有 stdout 行為不變。

## 驗證限制
- 新增 Python 靜態契約測試；它不等同於 WinForms 執行期測試。
- 尚未在 Windows 實機驗證剪貼簿、Ctrl／Shift 多選、DPI 或多螢幕行為。
