# 1.3.5 更新內容

## 圖片管理改善
- 圖片頁新增即時篩選，可搜尋原始檔名及圖片說明文字。
- 新增原始順序、檔名 A-Z、檔名 Z-A、最新加入優先、最早加入優先排序。
- 顯示目前符合條件的圖片數量及總關聯數。
- 篩選及排序只改變畫面呈現，不修改 SQLite 資料及原始圖片。
- 移除圖片仍只刪除資料庫關聯，不刪除硬碟原圖。

## 相依性與資料安全
- 無新增 NuGet 套件；SQLite Schema Version 1 不變。
- 原始 Excel 不會被修改。

## 測試狀態
- 已完成原始碼修改與 ZIP 結構檢查。
- 本環境未提供可用的 .NET SDK，因此未執行 Windows 編譯及 WinForms 實機測試。
