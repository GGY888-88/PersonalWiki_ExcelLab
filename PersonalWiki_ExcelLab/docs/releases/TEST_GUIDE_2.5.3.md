# PersonalWiki ExcelLab 2.5.3 測試指南

## A. 主畫面工具列文字不裁切
1. 在 Windows .NET 10 環境啟動桌面程式。
2. 依序在 Windows 顯示縮放 100%、125%、150%、200%、250%、300% 下啟動程式。
3. 確認主畫面工具列「新增條目」、「編輯條目」、「Excel 匯入精靈」、「輸入視窗按鈕大小...」等文字完整可讀。
4. 確認工具列可水平捲動，按鈕上下緣及文字沒有被裁切。
5. 在不同 DPI 下調整視窗大小並重新開啟，確認工具列仍完整顯示。

## B. 輸入視窗按鈕大小設定作用範圍
1. 開啟「輸入視窗按鈕大小...」，設定一組明顯尺寸，例如寬 240、高 80，儲存。
2. 點擊「新增條目」，確認輸入視窗中的「確定儲存／取消」按鈕依設定放大。
3. 開啟既有條目並點擊「編輯條目」，確認相同設定套用。
4. 返回主畫面，確認「新增條目／編輯條目」工具列按鈕不會跟著輸入視窗設定改變，且文字仍完整。
5. 將設定調回預設寬 160、高 64，再重複確認。

## C. 文件集中管理
- 確認所有歷代 `HANDOFF_*`、`UPDATE_NOTES_*`、`TEST_GUIDE_*`、`AUDIT_REPORT_*`、`DESKTOP_UI_TEST_MATRIX_*` 均位於 `docs/releases/`。
- 確認 `docs/releases/INDEX.md` 列出文件類型及最新交接文件。

## 測試限制
目前產出環境沒有 Windows、.NET SDK 或 PowerShell，因此本版僅完成程式碼與文件靜態檢查；上述 DPI 與桌面互動項目需在 Windows 實機執行。
