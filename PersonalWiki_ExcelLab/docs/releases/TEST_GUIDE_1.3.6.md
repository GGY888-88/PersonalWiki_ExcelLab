# 1.3.6 測試指南

1. 解壓縮後執行「啟動 PersonalWiki.bat」，開啟既有測試資料庫。
2. 按「圖片完整性檢查」，選擇一個新的 JSON 報告檔案。確認畫面統計與報告內容一致。
3. 按「重複圖片檢查」，另存 JSON 報告；確認只依 SHA-256 已記錄值分組。
4. 將一張測試圖片暫時改名或移至測試資料夾，再執行完整性檢查，應顯示遺失；測完請還原檔案。
5. 確認資料庫及原始圖片未被程式修改；請勿在正式資料庫上故意移動原圖測試。

注意：本包在產出環境未能執行 Windows .NET 編譯或 WinForms 實機測試，需在 Windows + .NET 10 SDK 環境驗收。
