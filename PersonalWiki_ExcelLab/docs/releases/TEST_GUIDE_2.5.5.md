# 2.5.5 測試指南

## 主畫面按鈕
1. 使用 2.5.5 全新設定檔啟動，開啟「主畫面功能按鈕大小」。確認預設寬 100、高 68。
2. 確認「新增條目」「編輯條目」等短標籤完整顯示；長標籤（例如「主畫面功能按鈕大小」）會自然增加寬度，保持單行，不被固定寬度壓成多行。
3. 將最小寬度改為 140、高度 68，確認所有按鈕至少 140px 寬，長文字仍可自然放寬。
4. 將高度調整後，確認工具列父層列高同步，不裁切按鈕上下緣。
5. 調整「輸入視窗按鈕大小」，確認主畫面工具列不變；反向測試亦同。
6. 使用 100%、125%、150%、200%、250%、300% Windows DPI 測試；跨螢幕時確認重新縮放及水平捲動。
7. 關閉重開，確認設定保留。

## 資料庫位置列
1. 開啟資料庫，確認「目前資料庫位置」文字框出現在按鈕列下方，未被按鈕列或搜尋列遮住。
2. 使用較長路徑，確認文字框填滿可用寬度；可點入後 Ctrl+A、Ctrl+C 複製。
3. 雙擊路徑框，確認完整路徑被全選並複製。

## 按鈕標籤
- 確認主畫面「開啟資料庫」「建立知識庫」「立即備份資料庫」及尺寸設定按鈕不再帶尾端省略號，按下後原本功能仍正常開啟。
