# 1.3.5 測試指南

1. 解壓縮 ZIP，保持資料夾名稱 `PersonalWiki_ExcelLab`。
2. 執行「啟動 PersonalWiki.bat」，開啟既有測試資料庫或建立新資料庫。
3. 選取含圖片的條目，進入「圖片」頁。
4. 在篩選欄輸入部分檔名或圖片說明，確認圖片卡片即時縮減；清空後應恢復。
5. 逐一切換五種排序，確認圖片順序變化及數量顯示正確。
6. 選取圖片後使用「移除選取圖片關聯」，確認只移除資料庫關聯，原始圖片檔仍存在。
7. 可使用 `samples/PersonalWiki_Import_Sample.xlsx` 測試 Excel 匯入流程；匯入前請先建立測試資料庫。

注意：此版本尚未在 Windows/.NET 10 環境完成編譯及實機驗收。
