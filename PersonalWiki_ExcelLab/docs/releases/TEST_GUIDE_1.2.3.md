# PersonalWiki ExcelLab 1.2.3－Windows 操作驗收

## 1. 啟動與資料庫
1. 在新版本資料夾執行：
   ```powershell
   dotnet run --project .\PersonalWiki.Desktop\PersonalWiki.Desktop.csproj -c Release
   ```
2. 按「開啟上次資料庫」載入原有資料庫；確認上方「目前資料庫位置」顯示原本的 `.db` 路徑。
3. 不要刪除、搬移或覆蓋原有 `.db`。`samples\PersonalWiki_Import_Sample.xlsx` 才是隨程式附帶的 Excel 測試檔。

## 2. 新增／編輯條目
1. 按「新增條目」，確認條目名稱、類型及摘要文字上下完整顯示。
2. 輸入測試條目並儲存，再選取該條目按「編輯條目」。
3. 確認摘要框可完整顯示多行文字，視窗可最大化或拉大。

## 3. 搜尋與封存／還原
1. 在名稱／摘要欄輸入完整名稱或其中一段文字，按 Enter 或「搜尋」。
2. 確認名稱片段及摘要片段都能找到資料。
3. 選取一筆條目，按「封存選取條目」。完成後會自動切換到「全部條目」。
4. 將篩選改成「已封存條目（還原用）」，選取該筆，按「還原選取條目」。完成後應回到全部條目並顯示「使用中」。

## 4. 筆記與圖片
1. 選取一筆條目，開啟「筆記」頁籤；操作按鈕應位於頁籤上方。
2. 新增及編輯多行筆記，確認文字沒有被上下裁切。
3. 開啟「圖片」頁籤，按「新增圖片關聯」，選一張 JPG 或 PNG，圖片說明可留空或輸入文字。
4. 再次選相同圖片：不應出現 SQLite UNIQUE 錯誤，不會新增重複卡片；輸入新說明會更新原說明，留空會保留舊說明。
5. 若選 WebP／SVG 等 Windows 圖形元件不支援的格式，應仍看到關聯卡片及無法預覽提示。移除關聯不會刪除硬碟原圖。

## 5. Excel 匯入（內附測試檔）
1. 先開啟一個測試用知識庫；建議先建立新的空白 `.db`，不要直接用唯一的正式資料庫測試。
2. 按「Excel 匯入精靈」，閱讀操作說明並選擇：`samples\PersonalWiki_Import_Sample.xlsx`。
3. 預覽畫面應看到「人物」工作表及 3 列資料。按「下一步：設定欄位用途」。
4. 在「人物」分頁設定：
   - `名稱` → **條目名稱（每張表必選一欄）**
   - `簡介` → **主要內容（摘要／介紹文字）**
   - `生日` → **屬性欄位（保存為自訂欄位）**
   - `代表作品` → **屬性欄位（保存為自訂欄位）**
   - 第一筆資料列保持第 2 列。
5. 確認欄位用途，選擇位置儲存欄位設定 JSON。接著選擇位置儲存資料檢查 JSON。
6. 檢查設定畫面建議先保留全部勾選。內附測試檔應可通過 Dry-run；若顯示需要人工檢查的資料列，程式會停止匯入並列出工作表、規則及 Excel 列號。
7. 選擇一個**不存在的新檔名**作為匯入前備份，例如 `wiki-before-import-test.db`。最後確認目標資料庫與備份路徑後才會開始匯入。
8. 匯入後在搜尋欄搜尋「範例人物甲」，確認簡介及自訂欄位有匯入。

## 6. 驗收限制
- 本版本在交付環境沒有 .NET SDK／Windows Forms，尚未完成 Windows Build 及實際 GUI 驗收。
- 請先使用獨立測試資料庫驗收，不要直接用唯一正式資料庫測試匯入。
