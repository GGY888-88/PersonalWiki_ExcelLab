# PersonalWiki ExcelLab 4.6.6 後續驗收指南

本輪依使用者要求不執行測試。後續如安排驗收，只檢查本版三個高度變更及必要的基本啟動：

1. Windows .NET 10 執行 `01_建置程式.bat`，確認編譯錯誤／警告。
2. 以 300% DPI 開啟主畫面，檢查資料庫路徑、全文搜尋、標籤三框是否比 4.6.5 緊湊，文字仍垂直置中。
3. 對照其他欄位、80×22 主功能按鈕及既有排列，確認沒有被改動。
4. 需要時再安排 100%／150%／200% DPI 與搜尋、複製路徑功能回歸。

本指南是後續待辦，不代表測試已執行。
