## 已完成版本與功能

- **1.3.4**：左側條目多選；批次封存／還原；操作前顯示筆數並要求確認；不刪除條目內容或圖片。
- **1.3.5**：圖片牆依檔名／說明即時篩選；支援原始順序、檔名升冪／降冪、加入時間排序；只改變顯示，不修改圖片或資料。
- **1.3.6**：圖片完整性與重複圖片檢查報告；依既有 SHA-256 核對；報告用途為人工複核，不自動刪除或合併。
- **1.3.7**：條目自訂欄位改為依 Excel 工作表呈現欄位標題及順序；不同工作表可有不同版面。
- **1.3.8**：同一工作表條目共用工作表欄位版面；缺少值顯示空白，不造成欄位錯位；不同工作表仍各自獨立；無來源工作表資訊的舊條目維持相容。
- **1.3.9**：修正整合驗收腳本未定義 `$temp` 的兩處報告路徑；修正 portable 建置腳本可能刪除既有 `publish` 資料夾的風險；新增 dotnet publish 結束碼檢查；自我測試輸出資料夾改為新路徑且拒絕覆蓋；同步 CLI／桌面版本與報告版本；整理 README、更新說明、測試指南及稽核報告。

較早版本的主要能力包括 1.2.0 桌面 Excel 匯入精靈、欄位 mapping、預覽、Dry-run／預檢，以及條目、筆記、圖片關聯、標籤、搜尋、備份／還原、資料庫稽核與匯出等功能；完整歷史更新紀錄保留在各 `UPDATE_NOTES_*.md`／`.txt` 與 README。

## 專案結構

- `Program.cs`：CLI 入口、命令路由、自我測試。
- `Models.cs`：共用資料模型。
- `Services/`：Excel 讀取／寫入副本、匯入 mapping／預檢／Dry-run／交易匯入、SQLite 查詢、備份／還原、稽核、搜尋及圖片檢查服務。
- `PersonalWiki.Desktop/`：Windows Forms 桌面程式；主要包含 `MainForm.cs`、`ImportDialogs.cs`、`TagManagementDialog.cs`、`DesktopSettingsService.cs`。
- `scripts/`：CLI／桌面建置、portable 發布、自我測試及整合驗收 PowerShell 腳本。
- `samples/`：Excel 測試樣本。
- `UPDATE_NOTES_*.md`、`TEST_GUIDE_*.md`：逐版更新及測試文件。
- `AUDIT_REPORT_1.3.9.md`：本次檢查範圍、已修正問題及後續風險。

## 資料安全限制與既有驗收原則

1. 原始 Excel 一律唯讀；如需修改 Excel，只能寫入明確指定的新副本，不得原地覆寫來源。
2. Excel 匯入正式資料庫前，必須保留既有預檢、資料庫健康檢查、建立新備份、驗證備份、交易式匯入及批次驗證流程。
3. 備份、還原、匯出及報告不得覆蓋既有目的檔；新輸出路徑已存在時應停止並要求新路徑。
4. 不可自動刪除、合併或重寫條目、筆記、標籤或來源追溯資料；除非使用者明確要求且有安全確認流程。
5. 移除圖片關聯只可移除資料庫關聯，不可刪除或移動硬碟原始圖片；不得自動複製或改寫原圖。
6. 不可擅自變更 SQLite Schema、資料庫位置或設定檔位置；若未來確實需要 Schema 變更，必須先提出 migration 計畫、備份與回復策略。
7. 不可移除或重做已完成版本功能；修改前先確認程式現況，盡量以局部修正及回歸測試完成。
8. 測試一律使用新建測試資料庫與測試檔，不可拿唯一正式資料庫做破壞性測試。

## 已知問題、未測試項目與環境限制

- 本次開發環境沒有 .NET SDK，且不是 Windows；1.3.9 未在此執行 `dotnet restore/build`、CLI 自動化測試或 Windows Forms 實機測試。
- 桌面啟動批次檔使用 `dotnet run`，執行端需安裝 .NET 10 SDK；免 SDK 的桌面發佈包尚未完成驗收。
- 整合驗收腳本以 CLI／SQLite 服務為主，尚無完整 WinForms UI 自動化覆蓋。
- Excel 自我測試不代表全面支援 XLSM/VBA、Excel COM、Power Query、外部連線、內嵌圖片、密碼保護工作表或超大型活頁簿。
- 部分 Service 程式碼較為壓縮，建議後續分批整理並補單元測試，不宜一次大規模重構。
- 1.3.9 測試指南已隨 ZIP 附上，但使用者目前沒有時間測試；不要要求使用者立即執行測試或回報結果。

## 下一階段 1.4.0 建議計畫

1. 將 CLI 自動化測試與桌面 UI 驗收分離，建立可重複執行且不覆蓋既有資料的測試矩陣。
2. 優先補上匯入預檢、備份、交易式匯入及批次驗證的回歸測試。
3. 補強 SQLite 備份／還原、圖片路徑失效、搜尋索引重建的邊界測試。
4. 再處理 DPI／縮放、多螢幕及不同工作表欄位顯示的 UI 驗收。
5. 評估免安裝桌面發佈包；先確定發佈方式，不可因此改動現有資料庫位置或資料格式。
6. 每完成一批可獨立交付功能，更新版本號、更新說明、測試指南及本交接文件，並產生對應完整 ZIP。
