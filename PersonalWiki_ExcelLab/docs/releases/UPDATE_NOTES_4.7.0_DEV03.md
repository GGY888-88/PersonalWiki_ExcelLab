# 4.7.0 DEV03 更新紀錄

## 新增
- 新增「Excel 批次差異比較」入口，可選擇兩次既有匯入批次進行唯讀比較。
- 顯示條目新增、移除、修改數量，以及自訂欄位新增、移除、修改摘要。
- 可將目前比較結果匯出為 UTF-8 JSON（不含 BOM）。
- 比較清單沿用既有 `ExcelImportBatchManagementService.List`，比較沿用 `ExcelImportBatchDiffService.Compare`。

## 保護範圍
- 不新增或修改 SQLite Schema。
- 不改變資料庫位置、Excel 匯入流程、來源檔案唯讀原則、匯入前備份或交易安全流程。
- 比較服務以 SQLite ReadOnly 模式開啟資料庫；JSON 僅寫到使用者選定的匯出位置。
- 保留既有匯入歷史視窗及其他功能。

## 操作方式
1. 開啟知識庫。
2. 點選「Excel 批次差異比較」。
3. 選擇較早及較新的匯入批次，再按「比較批次」。
4. 如需留存結果，按「匯出 JSON…」並選擇儲存位置。

## 驗證狀態
- 依使用者要求，本版未執行測試、未執行編譯、未啟動程式。
- 僅完成靜態檔案修改與內容檢視；Windows/.NET 10 執行結果尚未驗證。
