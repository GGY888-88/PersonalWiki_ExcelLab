# PersonalWiki ExcelLab 1.3.4 更新紀錄

## 條目批次封存／還原
- 左側搜尋結果支援 Ctrl／Shift 多選。
- 新增「批次封存／還原」操作。
- 執行前列出封存與還原數量並要求確認。
- 逐筆使用既有封存狀態服務；不刪除條目、筆記、圖片或檔案。
- 完成後切換至「全部條目」並重新搜尋。

## 相容性與安全
- SQLite Schema 維持 v1。
- 不新增 NuGet 套件。
- 原始 Excel 唯讀；圖片原始檔不因移除關聯而刪除。
- 內附啟動檔及 Excel 匯入測試樣本。

## 驗證限制
- ZIP 完整性與來源文字檢查可執行。
- 本建置環境未提供 .NET SDK，未執行 Windows Build 或 WinForms 實機測試。
