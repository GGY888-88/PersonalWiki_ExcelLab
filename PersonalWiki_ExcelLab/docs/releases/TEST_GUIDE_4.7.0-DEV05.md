# 4.7.0 DEV05 集中測試指南（尚未執行）

## 測試前準備
- Windows 10／11、.NET 10 SDK。
- 使用 DEV05 ZIP 解壓後的 `PersonalWiki_ExcelLab` 資料夾。
- 使用隔離測試資料庫；可由 `samples/PersonalWiki_3.6.0_Test.db` 複製一份後測試，禁止直接使用正式知識庫。
- 測試資料庫需至少有一筆具有共用標籤或相同類型推薦條件的相關條目。

## 驗收項目
1. 啟動程式並開啟隔離測試資料庫。
2. 選取一筆條目，進入「相關條目」頁。
3. 確認相關條目清單、推薦排序、共用標籤及相同類型欄位與 DEV04 相同。
4. 選取一筆相關條目，按「檢視相關條目摘要」，確認預覽顯示名稱、類型、更新時間、摘要及關聯依據。
5. 雙擊相關條目清單項目，確認開啟相同預覽視窗。
6. 確認摘要與關聯依據欄位唯讀，無新增、編輯、封存、刪除或合併操作。
7. 按「複製條目名稱」，貼到記事本確認文字正確。
8. 關閉預覽，確認主畫面原本選取條目、搜尋條件及資料清單均未改變。
9. 測試無摘要、長摘要、長標籤、多筆相關條目及沒有相關條目的情況。
10. 在 100%、150%、200%、300% DPI 檢查預覽視窗、文字換行、捲動及工作區邊界。
11. 確認資料庫內容及 `PRAGMA user_version` 未改變，版本仍為 1。
12. 回歸搜尋、標籤、筆記、圖片、來源追溯、Excel 匯入歷史、批次差異比較及 DEV04 Dry-run 問題明細。
