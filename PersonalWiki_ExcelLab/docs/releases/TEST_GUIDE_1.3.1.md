# PersonalWiki ExcelLab 1.3.1 測試指南

## 啟動
1. 解壓縮 ZIP。
2. 雙擊 `啟動 PersonalWiki.bat`。
3. 開啟既有資料庫或使用附帶的 Excel 測試檔建立測試資料。

## 全文搜尋驗收
在「全文搜尋」輸入以下資料中實際存在的片段，確認能找到所屬條目：
- 條目名稱或摘要
- 自訂欄位名稱或內容
- 筆記內容
- 標籤
- 圖片說明或圖片原始檔名

搜尋仍受類型及封存狀態篩選影響；若找不到，先將類型設為「全部類型」、封存狀態設為「全部條目」。清空搜尋文字可恢復清單。

## 資料安全
搜尋只讀取資料庫，不會修改條目、筆記、圖片檔案或 Excel 原始檔。

## 已知限制
按鈕尺寸自訂在高 DPI 環境仍未完成實機驗收，本版沒有宣稱修正該問題。
