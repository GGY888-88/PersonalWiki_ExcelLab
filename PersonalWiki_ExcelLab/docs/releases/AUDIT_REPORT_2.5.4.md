# 2.5.4 靜態稽核報告

## 根因確認
2.5.3 的主畫面按鈕仍使用 `PreferredSize` 在 MainForm 建構期間計算一次列高。WinForms 此時尚未完成顯示器 DPI／最終字型配置；按鈕後續的實際高度可能改變，但父層 TableLayoutPanel 的固定列高沒有在 DPI 套用後同步調整。另一個混淆點是原有尺寸設定呼叫 `LoadEntryButtonSize()`，只傳給 `EntryEditDialog`，不會作用於 MainForm 工具列。

## 2.5.4 修正
- 新增主畫面專用設定欄位及讀寫方法，與輸入視窗設定分離。
- 主畫面工具列按鈕使用設定的固定寬高，按鈕列高依實際 DPI 換算後同步更新。
- `Shown` 與 `DpiChanged` 均重新套用設定。
- 工具列採單列水平捲動，避免加寬後自動換行。
- 保留舊設定 JSON 的相容預設值。

## 風險與限制
主畫面工具列的按鈕寬度由使用者設定；若刻意設得過小，文字仍可能無法完整顯示，因此預設值提高至 220 px，並允許使用者調大。最終顯示仍須在 Windows 實機驗收不同 DPI、字型及多螢幕情境。
