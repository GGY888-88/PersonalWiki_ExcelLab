# PersonalWiki ExcelLab 2.5.4 桌面 UI 驗收矩陣

| 情境 | 主畫面按鈕設定 | 輸入視窗按鈕設定 | 預期結果 |
|---|---|---|---|
| 初次啟動舊設定檔 | 無新欄位，使用預設 220×64 | 保留原設定或預設 160×64 | 舊 JSON 可讀，不要求重建 |
| 主畫面尺寸設定 | 260×80 | 不變 | 工具列所有功能按鈕立即變更，列高同步增加 |
| 輸入視窗尺寸設定 | 不變 | 180×72 | 僅新增／編輯對話框的確定儲存／取消變更 |
| 主畫面尺寸縮小 | 180×48 | 不變 | 工具列按鈕同步縮小，列高同步縮小 |
| DPI 100%–300% | 依 DeviceDpi 比例換算 | 依 EntryEditDialog 現有邏輯 | 不裁字，兩組設定作用範圍獨立 |
| 跨螢幕 DPI 變更 | DpiChanged 後重套用 | 依對話框自身 DPI | 主畫面按鈕與父層列高同步更新 |
| 工具列寬度不足 | 使用已設定寬度 | 不變 | 單列水平捲動，不換行 |
| 重啟程式 | 讀取保存值 | 讀取保存值 | 兩組設定分別保留 |

本矩陣需於 Windows 實機執行；目前打包環境非 Windows，未宣稱已通過。
