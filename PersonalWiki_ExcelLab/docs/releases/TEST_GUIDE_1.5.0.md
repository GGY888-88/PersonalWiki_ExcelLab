# PersonalWiki ExcelLab 1.5.0 測試指南

## A. CLI 自動化驗收（可延後執行）

1. 在 Windows 10/11 安裝 .NET 10 SDK。
2. 解壓 ZIP 至新資料夾，勿將測試輸出指向正式資料庫所在資料夾。
3. 在 PowerShell 執行：

   ```powershell
   .\scripts\run-acceptance-tests.ps1 -OutputRoot .\AcceptanceTestOutput_150
   ```

4. 腳本會建立全新的測試資料庫與測試 Excel，目的輸出資料夾若已存在會停止，不會覆蓋。
5. 檢查 `AcceptanceTestOutput_150\AcceptanceTestReport.json` 的 Passed／Failed 統計。

自動化測試涵蓋 CLI、自我測試、SQLite 健康檢查、備份／還原、逐表筆數及資料內容比對、目的檔防覆蓋、相同路徑拒絕、損壞資料庫拒絕、全文索引重建及既有稽核報告。

## B. Windows 桌面人工驗收（有空再做）

1. 使用測試資料庫，不要使用唯一正式資料庫。
2. 以 100%、125%、150%、200% Windows 顯示縮放啟動桌面程式，檢查按鈕、標籤、輸入框是否裁切。
3. 在單螢幕與雙螢幕間移動視窗，檢查視窗尺寸、分隔面板及圖片頁顯示。
4. 載入不同 Excel 工作表來源的測試條目，確認欄位名稱及順序依工作表區分；同工作表缺值顯示空白。
5. 多選條目執行批次封存／還原，確認筆記及圖片關聯仍存在。
6. 圖片完整性／重複報告僅檢視，不執行自動刪除或合併。

## 安全提醒

- 不以正式資料庫做首次測試。
- 原始 Excel 應保持唯讀。
- 移除圖片關聯不得刪除硬碟原始圖片。
- 備份、還原、報告與匯出目的檔若已存在，應改用新路徑，不要手動覆蓋。
