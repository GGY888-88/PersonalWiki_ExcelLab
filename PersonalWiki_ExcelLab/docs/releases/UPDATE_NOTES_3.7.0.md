# 3.7.0 更新說明（目前整合開發版）

- 搜尋新增建立日期起／迄及更新日期起／迄四個可選條件；迄日包含整個當日，透過次日零時排他上界實作。
- 日期格式固定 `yyyy-MM-dd`；無效日期或起日晚於迄日會拒絕查詢。
- 日期、全文關鍵字、類型、標籤及封存狀態採 AND 交集。
- 桌面搜尋列新增標籤、日期欄位、排序及「清除條件」；清除會重設全部搜尋條件與頁碼。
- CLI `entry-query` 新增 `--sort`、`--created-from`、`--created-to`、`--updated-from`、`--updated-to`。
- 保留 3.6.0 排序、唯讀查詢、分頁上限及批次標籤查詢。
- SQLite Schema、NuGet 套件、DB／設定檔路徑不變。
