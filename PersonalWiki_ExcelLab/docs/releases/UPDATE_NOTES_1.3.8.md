# PersonalWiki ExcelLab 1.3.8 更新說明

## 工作表版面一致化
- 同一 Excel 工作表匯入的條目，現在共用該工作表的欄位版面。
- 版面欄位以該工作表所有已匯入欄位為基礎，依 `sort_order` 排序。
- 某筆資料缺少某欄位時，該欄顯示空白，不會造成其他欄位錯位。
- 不同工作表仍各自使用自己的欄位版面。
- 沒有來源工作表資訊的舊條目，保留原本依自身欄位顯示的方式。

## 安全與相容性
- SQLite Schema 維持 v1，無資料庫遷移。
- 不新增 NuGet 套件。
- 不修改來源 Excel。
- 不修改或刪除圖片原檔。
- 本次只讀取既有 `entry_fields.source_sheet` 建立顯示版面，不改寫資料。

## 驗證限制
- ZIP 完整性檢查可執行。
- 目前建置環境沒有 .NET SDK，尚未完成 Windows 編譯及 WinForms 實機測試。
