# PersonalWiki ExcelLab 4.7.0 開發更新紀錄（DEV01）

## 新增功能：標籤使用統計 JSON 報告
- 在既有「標籤管理」視窗增加「使用統計報告」按鈕。
- 重用既有 `DatabaseTagUsageReportService`，以 SQLite ReadOnly 模式產生 JSON 報告。
- 報告提供標籤總數、含標籤條目數、標籤關聯總數、單次使用標籤數、多次使用標籤數及使用分布。
- 使用者選擇新檔案輸出；不覆蓋既有報告。
- 不新增／修改 SQLite Schema，不修改條目、標籤或任何資料庫內容。
- 原有標籤重新命名／合併、刪除、CSV 匯出、重新整理功能不變。

## 版本資料
- CLI 與 Desktop 專案版本標示更新為 4.7.0。
- 三個標準 BAT 的版本訊息更新為 4.7.0，維持 ASCII 與 CRLF。
