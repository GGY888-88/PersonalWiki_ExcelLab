# PersonalWiki ExcelLab 1.3.6 更新說明

## 圖片完整性與重複檔案檢查
- 主畫面新增「圖片完整性檢查」：以唯讀方式檢查資料庫中的圖片路徑、檔案是否存在，以及資料庫已記錄的 SHA-256 是否相符，輸出 JSON 報告。
- 新增「重複圖片檢查」：依資料庫已記錄的 SHA-256 分組，輸出包含條目、圖片關聯及路徑的 JSON 報告。
- 兩項功能均不修改 SQLite、不修改圖片原檔、不刪除或合併圖片關聯。
- 重複檢查只涵蓋已有 SHA-256 的資料；未記錄雜湊的圖片不會被納入。完整性檢查會實際讀取有雜湊紀錄的圖片內容計算 SHA-256，圖片數量大時可能耗時。

## 安全提醒
報告包含本機資料庫路徑及圖片檔案路徑，請勿未檢查便公開分享。

## 相依性與資料格式
無新增 NuGet 套件；SQLite Schema 維持 v1。
