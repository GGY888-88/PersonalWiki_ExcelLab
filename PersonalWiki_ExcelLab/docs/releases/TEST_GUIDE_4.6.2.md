# 4.6.2 DPI 自適應測試指南

## 環境
- Windows 10／11
- .NET 10 SDK
- Python 3
- 請優先在目前回報的 Windows 300% 環境驗收；另建議使用至少 1920×1080 顯示器檢查一般工作區。

## 自動測試
在專案根目錄執行：

```powershell
python scripts/test-4.6.2-dpi.py
python scripts/test-4.6.2-responsive-tables.py
python scripts/run-4.6.2-python-tests.py
```

## 編譯與啟動

```powershell
dotnet build PersonalWiki.Desktop/PersonalWiki.Desktop.csproj -c Release
dotnet run --project PersonalWiki.Desktop/PersonalWiki.Desktop.csproj -c Release
```

## Windows DPI 實機矩陣
依序將 Windows「設定 → 系統 → 顯示器 → 縮放」切換為下列比例，重新啟動程式並檢查主畫面及 Excel 匯入精靈：

| 比例 | 檢查重點 |
|---|---|
| 100% | 基準尺寸，標籤、輸入框及按鈕完整顯示 |
| 125% | 搜尋列、資料庫路徑及精靈標籤不裁切 |
| 150% | 第 2 步「第一筆資料列」輸入列可見，按鈕不重疊 |
| 175% | 預覽／欄位表格可捲動，精靈按鈕不超出視窗 |
| 200% | 三個精靈步驟均能在工作區內操作 |
| 300%（本次回報環境，優先驗收） | 全文搜尋輸入框與筆記／圖片工具列文字完整顯示；篩選條件分成兩列固定成組，不得被擠壓或直排；建立及更新日期起迄均可見，獨立核取方塊與日期輸入框之間有間距且不重疊；單列內容超出寬度時僅該列水平捲動；搜尋／清除／分頁操作列獨立顯示；Excel 預覽儲存格文字完整顯示，表格下方空白區為白色工作區而非大片灰色；視窗在工作區內 |

如果有不同縮放比例的多螢幕，請將視窗從 100% 螢幕移至 150% 或 200% 螢幕，再移回，確認字型、按鈕尺寸及視窗位置重新調整。

## 主畫面檢查
1. 資料庫路徑顯示在搜尋列前段；點選後可 Ctrl+A／Ctrl+C，長路徑可左右移動檢視。
2. 搜尋條件按兩列固定分組：第一列為資料庫、全文搜尋、類型、封存狀態及標籤；第二列為建立日期起迄、更新日期起迄及排序。各組「標籤＋輸入框」固定成組且不自動換行；若某列可用寬度不足，只允許該列水平捲動。搜尋／清除／複製摘要／上一頁／頁碼／下一頁應位於篩選列下方的獨立操作列（整個主畫面頂端共四列：主功能列、一般篩選列、日期／排序列、查詢操作列），不得被主結果清單覆蓋或裁切。兩列篩選應緊接排列，不得有不必要的大段垂直空白。日期條件的核取方塊與日期選擇器是兩個獨立控制項，應分開顯示且不得交疊。
3. 全文搜尋輸入框的文字需完整顯示，不可只看到上半部；輸入游標、底線及控制項邊框均不可被裁切。
4. 視窗最大化、縮小及拖曳至螢幕邊緣時，不應超出工作區。
5. 筆記頁「新增筆記／編輯選取筆記／刪除選取筆記」及圖片頁「新增圖片關聯／編輯圖片說明／檢查圖片檔案／移除選取圖片關聯」的按鈕文字須完整顯示，下半部不得被工具列邊界裁切。
6. 搜尋、分頁、結果選取與功能按鈕操作正常。

## Excel 匯入精靈檢查
1. 使用 `samples/PersonalWiki_Import_Sample.xlsx`（若封裝中沒有此檔，使用既有測試 Excel 樣本）。
2. 第 1 步：工作表資訊標籤可換行；資料預覽表格可水平／垂直捲動；欄標題與每列文字需完整顯示，不得出現列高不足造成的上下裁切。
3. 第 2 步：Excel 標題列、第一筆資料列、數值輸入框及括號提示完整可見；窄視窗時控制項可換行；資料表格可捲動。
4. 第 3 步：所有檢查項目標籤完整顯示；長文字可換行；核取方塊可操作；確認／取消按鈕完整可見。
5. 各步驟取消時不應寫入資料庫；僅進行預覽與欄位設定測試即可。

## 資料安全與回歸
- 若執行真實匯入，必須使用測試資料庫副本及全新備份檔案路徑，不可使用正式資料庫。
- 確認原始 Excel 不被修改。
- 確認 SQLite Schema／`PRAGMA user_version` 未變更；本版不含 migration。

## 300% 表格欄寬驗收（最新 Hotfix）
1. 主畫面左側搜尋結果清單：名稱、類型、摘要、更新時間及狀態欄應依左側面板寬度分配；一般視窗寬度下應填滿可用寬度，窄面板時允許水平捲動，不能將文字欄壓至不可讀；若欄位最小寬度總和小於可用 client width，不應因 1–2px 原生邊框誤差出現水平捲軸。
2. 右側「相關條目」：相關條目、類型、共用標籤數、共用標籤、相同類型及更新時間欄應填滿右側表格寬度，不應只集中在左上角並留下大面積未使用的水平空間。
3. 拖曳主畫面中間 SplitContainer 分隔線，確認左右兩側欄寬會重新分配，不出現欄位重疊。
4. Excel 匯入精靈第 1 步：預覽表格的欄寬應填滿表格可用寬度；名稱／描述等較長欄位應取得較多空間；資料列換行與自動列高仍正常；欄位很多時可水平捲動。
5. 以上只檢查顯示與操作，不執行正式資料匯入。
