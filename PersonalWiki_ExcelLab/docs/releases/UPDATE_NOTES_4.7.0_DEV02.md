# 4.7.0 DEV02 更新紀錄

## 新增
- 主畫面新增「Excel 匯入歷史」入口。
- 新增唯讀匯入批次歷史視窗，最多顯示最近 500 筆批次。
- 顯示來源檔案、批次狀態、來源／匯入／拒絕列數及批次 ID。
- 選取批次後顯示來源 SHA-256、時間、條目／欄位／筆記／圖片／標籤／來源追溯數量、全文索引缺漏及外鍵違規數。

## 安全與相容性
- 重用既有 `ExcelImportBatchManagementService`。
- 查詢服務使用 SQLite ReadOnly 連線。
- 不新增資料表、不修改 Schema、不寫入資料庫。
- 不改變 Excel 匯入預檢、備份、交易或匯入流程。
- 未修改 4.6.6 三個輸入框、主按鈕尺寸與 DPI 排列。

## 測試狀態
依使用者要求，本次不執行測試、不編譯。此工作包屬開發中版本，尚未 Windows 驗收。
