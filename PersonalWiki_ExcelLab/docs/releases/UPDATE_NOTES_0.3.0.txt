相依套件：無新增；沿用 DocumentFormat.OpenXml 3.5.1、Microsoft.Data.Sqlite 10.0.14。
測試：目前環境沒有 dotnet SDK，尚未編譯或執行測試；需在有 .NET 10 SDK 的 Windows 環境實測 FTS5 支援及 CRUD。
