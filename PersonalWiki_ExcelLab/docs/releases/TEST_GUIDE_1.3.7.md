# 1.3.7 測試指南

1. 使用 `啟動 PersonalWiki.bat` 啟動桌面程式。
2. 建立一個新的測試資料庫（不要使用唯一正式資料庫做首次測試）。
3. 建立測試 Excel，至少包含兩張工作表：
   - 工作簿1：名稱、地址、電話、備註。
   - 工作簿2：名稱、品牌、價格、分類、庫存。
4. 在匯入精靈中，分別為兩張工作表指定各自的條目名稱、主要內容及屬性欄位；完成匯入。
5. 搜尋工作簿1的條目，開啟「自訂欄位」：應顯示地址、電話、備註等各自的欄位欄頭。
6. 搜尋工作簿2的條目：應顯示品牌、價格、分類、庫存等欄頭，且不應沿用工作簿1的欄位。
7. 檢查欄位順序是否符合匯入精靈設定的 Excel 欄位順序。
8. 再開啟舊版資料庫中的手動建立條目，確認仍可正常顯示。

注意：此版本不會自動產生欄位以外的表單元件，也不會改變條目編輯視窗；它調整的是條目詳細頁「自訂欄位」的表格呈現。請先在測試資料庫驗證，不會修改來源 Excel。
