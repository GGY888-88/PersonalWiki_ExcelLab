# PersonalWiki ExcelLab 5.0.0 開發路線圖

## 目標與原則
目標版本：5.0.0。開發基準：4.6.6。採「全面強化」方向，兼顧個人知識管理與 Excel 資料管理。

本文件是開發路線，不代表所有候選功能已獲准實作。新增功能先以不改 Schema、不改資料路徑、不改既有匯入安全流程為原則；若功能必須變更這些項目，先取得使用者明確同意。

### 必須保護的既有項目
- 主功能按鈕 80×22 設定及 300% DPI 排列。
- 資料庫路徑、SQLite Schema（目前 user_version=1）、既有資料與設定路徑。
- 搜尋、日期篩選、標籤交集、排序、分頁、多選摘要複製。
- Excel 匯入預檢、唯讀來源、匯入前新檔備份、交易安全及批次追溯。
- 備份／還原安全、圖片關聯不刪除硬碟原圖。
- 其他目前正常的輸入框、日期欄位、ComboBox、列表及右側內容區。
- .NET 10、DocumentFormat.OpenXml 3.5.1、Microsoft.Data.Sqlite 10.0.14。

## 版本階段

### 4.7.0 — 操作體驗與功能盤點
1. 完成主畫面、條目編輯、筆記、圖片、標籤管理、Excel 精靈的功能／控制項清冊。
2. 以不變更既有資料模型為前提，提出可獨立交付的 UX 改善候選。
3. 優先候選：搜尋條件快速清除／保存、結果清單操作效率、條目內容檢視便利性、匯入流程狀態提示。
4. 新增標籤使用統計 JSON 報告入口，重用唯讀服務，不改 Schema。
5. 不在本階段擅自改動 4.6.6 三個輸入框以外的 UI。

### 4.8.0 — 知識管理效率
候選項目（實作前需確認）：
- 條目批次操作的可預覽／可取消流程。
- 標籤探索、使用量與未使用標籤的整理報表。
- 相關條目導覽與來源追溯的可讀性。
- 筆記與圖片關聯的操作效率、狀態提示。
- 重複條目報告的檢視與人工處理輔助；不自動合併或刪除。

### 4.9.0 — Excel 與資料維護效率
候選項目（實作前需確認）：
- Excel 匯入批次歷史的檢視、差異與結果摘要。
- 匯入設定檔的管理便利性；不得改變現有預檢及交易安全。
- 匯出欄位選擇、匯出結果摘要與檔案安全提示。
- 資料庫健康、備份、圖片完整性及重複資料報告的入口整理。
- 長時間操作的進度、取消與錯誤摘要（先確認服務可安全取消）。

### 5.0.0 — 整合與正式發行
1. 將已確認且完成的 4.7–4.9 功能整合。
2. 統一操作說明、錯誤訊息與狀態回饋。
3. 完成資料安全、匯入／匯出、備份還原、搜尋及 DPI 回歸。
4. Windows .NET 10 Release 建置，錯誤 0、警告 0（若環境允許）。
5. 發行完整 ZIP、ZIP CRC、SHA-256、三個 BAT、Schema／套件／結構／版本歷史／問題與續開發文件。

## 開發節奏
- 先完成一批互相獨立的功能，再集中安排測試。
- 使用者明確要求暫緩測試時，只做程式／文件開發與差異整理，不宣稱測試通過。
- 不為了新功能重做舊版；不擅自變更已完成且正常的功能。
- 每次修改列出檔案清單、影響範圍、回退方式及未處理事項。
- 發行版本解壓後根目錄固定為 `PersonalWiki_ExcelLab`。
- 每版保留 `01_建置程式.bat`、`02_啟動程式.bat`、`03_建置並啟動.bat`。
