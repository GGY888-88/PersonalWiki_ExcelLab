# PersonalWiki ExcelLab 4.6.6 功能與控制項盤點（來源盤點）

> 本文件依 4.6.6 原始碼整理；屬靜態閱讀紀錄，未執行測試或 Windows 實機驗收。

## 主畫面功能
- 資料庫：建立知識庫、開啟資料庫、開啟上次資料庫、顯示目前資料庫路徑。
- 條目：新增、編輯、封存／還原、批次封存／還原。
- 查詢：全文關鍵字（名稱、摘要、筆記、自訂欄位、標籤及圖片說明）、類型、封存狀態、標籤、建立日期起迄、更新日期起迄、排序、分頁。
- 結果：多選、複製選取摘要、清除條件。
- 內容分頁：摘要、自訂欄位、筆記、圖片、標籤、來源追溯、相關條目。
- 管理與診斷：標籤管理、重複條目檢查、圖片完整性檢查、重複圖片檢查、資料庫健康檢查、立即備份。
- Excel：Excel 匯入精靈，包含工作簿預覽、欄位用途對應、資料清理規則、Dry Run／人工確認、匯入前備份及正式匯入。

## 輸入控制項分組
### 自訂垂直置中控制項
- 資料庫路徑：唯讀，可選取／複製。
- 全文搜尋：單行，支援 Enter 搜尋，提示文字說明可搜尋範圍。
- 標籤篩選：單行，完整標籤名稱，與其他條件採 AND 交集。

### 主畫面其他原生控制項（不應連帶替換）
- 類型：可輸入 ComboBox。
- 封存狀態、排序：下拉選單。
- 建立／更新日期：獨立核取方塊搭配 DateTimePicker。
- 圖片篩選：原生單行 TextBox；圖片排序 ComboBox。
- 摘要：唯讀多行 TextBox。
- 結果、欄位、筆記、標籤、來源、相關條目：ListView。
- 圖片：FlowLayoutPanel 與縮圖快取。

### 對話框與精靈（需逐檔盤點）
- 條目新增／編輯：名稱、類型、摘要等欄位；摘要為多行。
- 標籤管理：獨立管理對話框。
- Excel 匯入：工作簿預覽、欄位對應、清理規則編輯等步驟。
- 通用 Prompt：目前採多行輸入，不能因單行欄位修正而改成單行。
- 重複條目報告：唯讀檢視用途。

## 已有服務能力（依服務檔名及主畫面呼叫盤點）
- 條目查詢、內容、標籤、相關條目、搜尋索引維護。
- SQLite 備份、復原、健康／完整性／Schema／關聯／欄位／標籤／筆記／圖片等診斷報告。
- Excel 工作簿讀取、驗證、預覽、欄位映射、清理規則、Dry Run、匯入批次差異與驗證。
- 安全檔案輸出、套件完整性、查詢計畫與 Benchmark。

## 5.0 功能候選優先順序（待確認）
1. 搜尋工作流程效率（保存常用條件／快速套用）：需先設計儲存位置；不可擅改設定格式。
2. 條目與標籤導覽效率：優先重用現有 RelatedEntry／Tag 服務。
3. Excel 匯入批次檢視：先盤點現有批次 audit／diff 服務，優先只讀呈現。
4. 資料庫維護中心：整合既有健康、備份、圖片與完整性報告入口，不重複實作底層服務。
5. 操作回饋：長任務進度、錯誤摘要與可取消性；取消前需確認服務與交易安全。

## 明確禁止未經同意的變更
- SQLite Schema、資料庫路徑、桌面設定路徑。
- Excel 匯入安全流程、來源唯讀原則、交易與備份保護。
- 自動刪除、合併條目／筆記／標籤／來源資料或硬碟原圖。
- 主功能按鈕 80×22、300% DPI 排列及 4.6.6 三個輸入框以外的正常 UI。
